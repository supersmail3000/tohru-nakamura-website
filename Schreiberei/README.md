# Schreiberei

Landing page for Schreiberei - Home to Bar Tatar & Tohru.

## Overview

Schreiberei is a minimalist landing page that serves as the gateway to two exceptional restaurants:

- **Bar Tatar** - [bartatar.de](https://bartatar.de)
- **Tohru** - [tohru.de](https://tohru.de)

## Tech Stack

- Vanilla HTML5
- CSS3 with Custom Properties
- No JavaScript frameworks required

## Project Structure

```
├── index.html          # Main landing page
├── styles.css          # Stylesheet
├── images/             # Logo and image assets
│   ├── logo-schreiberei.svg
│   ├── bar-tatar-logo.svg
│   ├── tohru-logo.svg
│   └── ...
├── .gitignore
└── README.md
```

## Development

Simply open `index.html` in a browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

## Deployment

This is a static site that can be deployed to:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting provider

## Design

The design follows a warm, elegant aesthetic with:
- Background: #ccc6b2 (warm beige)
- Typography: Visuelt Pro
- Accent colors: Gold (#c6b47b), Black (#101010), Burgundy
